# AICC Bot

A Discord bot for managing AICC competitions and participants.

## Features

* Link Discord accounts to Kaggle and Nitro usernames
* Register participants for upcoming rounds
* Start and manage competition rounds
* Distribute tasks to registered participants
* Track participant entries and start times
* Manage ratings and rating progression
* View rankings and participant statistics
* Submit and review task suggestions/submissions
* Manage competition data through CSV files

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/KingGior007/aicc-bot.git
cd aicc-bot
```

### 2. Install the requirements

```bash
pip install -r requirements.txt
```

### 3. Set your Discord bot token

```bash
export DISCORD_TOKEN="your_token_here"
```

### 4. Run the bot

```bash
python3 bot.py
```
